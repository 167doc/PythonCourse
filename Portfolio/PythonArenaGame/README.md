Python Arena Game

Konzolová tahová bojová hra vytvořená v Pythonu v rámci mého studia programování.

Projekt demonstruje využití objektově orientovaného programování, práci s více moduly a vzájemnou interakci mezi objekty.

Funkce
souboj dvou bojovníků
náhodné hody kostkou
útok a obrana
výpočet způsobeného poškození
sledování životů bojovníků
grafické zobrazení zdraví
automatický průběh souboje
náhodné určení prvního útočícího bojovníka

Použité technologie:
Python
Objektově orientované programování (OOP)
Moduly a importy
random
Práce se stavem objektů

Struktura projektu:
arena.py – řídí průběh souboje
bojovnik.py – reprezentuje bojovníka a jeho vlastnosti
kostka.py – simuluje hod kostkou
main.py – vytváří objekty a spouští zápas
Spuštění

Projekt lze spustit pomocí souboru main.py.

python main.py
Stav projektu

Projekt je dále rozvíjen a v průběhu studia jsou postupně přidávány nové funkce a vylepšení.
